# NULL GENESIS V4.5

V4.5 separates the logical ASCII grid from its square presentation. Original and
V3 artwork, identities, encrypted envelopes and export archives remain in their
existing locations; the new release writes only to `dist/v45`.

The vocabulary contains 742 curated values: the complete original 420, all 110
V3 additions and 212 new structural/render/motion values. The 2,400 recipe
programs are a separate registry. They combine source geometry and executable
operators; supply retains 1,900 Common, 900 Uncommon, 400 Rare, 110 Epic and all
23 named Legendary phenomena. Every new edition has a deterministic timeline.

## Local NVIDIA studio

Run `native/launch.ps1` from PowerShell on Windows x64 with an NVIDIA driver.
It installs the listed dependencies into an isolated project runtime. Geometry,
surface sampling, normals, lighting, glyph encoding, animation poses, fragment
depth resolution and still/video-frame rasterization run on CUDA. JSON, AES,
gzip, PNG compression, archive packaging and FFmpeg video compression run on
the CPU. MP4/WebM exports use software codecs; CUDA frame rendering does not
imply NVENC support on the installed GPU.

Public hosting serves accepted CUDA stills and timelines. Its live laboratory
uses browser WebGPU or the preserved CPU reference backend, which is a preview
of the scene and is not claimed to reproduce CUDA shading byte for byte.
WebGL2 presents V4.5 cached ASCII cells with the same measured glyph atlas. A
remote website cannot access the local CUDA driver. Owner keys stay local and
are excluded from the public tree, archives and Git.

## Composition and encoding

Native grids are 30, 50, 64, 80, 96 and 120 square cells. Presentations are 300,
600 or 1200 square pixels; the standard release uses 600. Each resolution has
a separate DNA fingerprint. Enlarging a presentation does not add ASCII cells.

Eight framing programs cover tight portraits, head/torso, half/full bodies,
wide creatures, vertical relics, masks and distributed abstractions. Portrait
programs carve a crop plane into the implicit field. Wide/relic modes adjust
proportions; distributed modes separate source ownership bands. The camera
then iteratively measures the actual visible subject, excluding stage object
IDs, recenters in its view plane and fits an approximately 80% bounding span.
Subtraction fields move with their positive geometry. The grid introduces a
small discrete allowance around the 70–85% target.

The compiler budgets primary, accessory, tertiary and stage geometry before
rendering. CUDA samples the signed fields, uses key/fill/rim lighting with AO
and shadows, and probes secondary depths and surface curvature to separate
cavities and thin structures. Material texture has a bounded contribution.
The encoder then measures neighboring occupancy, depth jumps, normal changes,
semantic layers and calibrated coverage. It preserves primary contours,
prunes isolated peripheral cells, quantizes stable normal clusters, uses
world-anchored tie breaking and row-local ASCII error diffusion. Temporal,
depth, edge and controlled noise parameters are authenticated parts of DNA.
The 20 Method programs alter those fields and material/encoder settings; their
names describe the dominant behavior rather than a separate trained model.

## Validation and reproducibility

Quality records expose ten classes of repeatable engineering proxies, including
frame fill, component coherence, noise, balance, tonal readability, trait
registration and actual animated motion. Subject confidence and NFT appeal are
heuristic labels, not learned recognition or predictions of financial value.
Visual contact-sheet review remains a separate gate.

Repairs have finite budgets and record reasons, pre/post measurements, actions
and outcomes. Uniqueness checks include exact ASCII/DNA/geometry, perceptual
tone/silhouette descriptors, glyph histograms and sampled motion trajectories.
The first timeline frame must equal the accepted still; geometry must move and
the repeated endpoint must match. Full timelines and the preceding wrap frame
are inspected numerically. Legendary formation/destruction deliberately has
larger transitions than Common anatomical drift.

The lossless XOR codec is selected only when it compresses better than the
original interleaved cells, and its inverse is checked before export. Each
archive contains ASCII, the 600-pixel PNG, portable GPU animation HTML,
lossless frames, metadata, DNA and a detailed quality JSON. All 23 Legends
also include MP4 and WebM. Other videos are generated on demand with the native
CLI or browser recorder. Private work checkpoints contain protected plaintext
and must never be copied into public hosting.

Extract every ZIP part into the same folder. Large Legendary video bundles can
span parts; the archive index lists those editions. Individual public assets
stay below 25 MiB. Completed parts are reused only after matching every entry
against its current source and checking ZIP integrity.

GPU memory pools, bounded animation batches, the resident glyph atlas and
source/compiler/architecture keyed NVRTC cache avoid repeated allocations and
compilation. The cache validates the compiled payload digest. Benchmark reports
record the actual device, memory pool, timings and six-grid visual comparisons;
they make no universal performance guarantee.

The six density budgets constrain primary and secondary geometry capacity,
tertiary size pruning, stage capacity, ambient signal and motion amplitude.
Changing a budget changes the compiled program where its limit applies.
`density-compatibility.json` records that all 3,333 prepared default candidate
fingerprints remained unchanged when these controls were connected.

## Regeneration

Use the Python interpreter where `native/requirements.txt` is installed. These
commands assume that interpreter is named `python` and Node.js is on PATH:

```powershell
python native/tools/calibrate.py --output native/work/calibration.json
python native/tools/atlas_v45.py
node scripts/prepare-v45.mjs
python native/experiment_v45.py
python native/tools/review_v45_experiments.py
```

Review all comparison sheets and grid samples. Record the chosen native grid,
review findings and `visual_review_approved` in the experiment report before:

```powershell
node scripts/prepare-v45.mjs mode=collection grid=80
python native/release_v45.py
python native/report_v45.py
python native/tools/verify_v45_crypto.py
python native/tools/verify_v45_videos.py
npm test
npm run build
```

The production runner refuses an unreviewed experiment report or a different
resume manifest. A release marker is written only after all 3,333 editions and
their exports have passed validation. Final production visual review and archive
CRC checks precede packaging and GitHub push. The original and V3 owner keys
are never used for V4.5; its key is `native/private/v45-owner.key`.

If generation finished but archive assembly was interrupted, use
`python native/release_v45.py --finalize-only`. This requires all 3,333 frozen
checkpoints and public records, rechecks candidate identities and every export
hash, verifies a CUDA golden still, then completes archives and the release
audit without rerunning generation.

After visual inspection, record the reviewed image hashes and approval in
`production-visual-review.json` and `collection-audit.json`. The web build refuses
unreviewed releases. `native/tools/freeze_v45_experiments.py` records a completed
experimental review; run it only after actually inspecting its twelve sheets.
After inspecting all five production sheets, run
`python native/tools/freeze_v45_production.py`, then
`node scripts/validate.mjs --report`. The clean local distribution can then be
created with `python scripts/package-v45.py --output C:\path\to\empty-folder`.
This packaging command requires successful release/build audits, verifies every
copied file hash, and omits keys, private checkpoints and runtime dependencies.

The accepted experimental study measured median still times of 14.28, 19.03,
20.27, 27.57, 35.17 and 48.02 ms for the six grids on a Quadro T1000. The 80-cell
grid was selected for visible cavity/accessory separation and comparable quality
to the larger grids. These are measurements for this device and experiment.
`performance.json` separately records warm NVRTC caching and zero additional GPU
allocations across twelve repeated stills. Driver module loading remains part of
startup time even when compilation is cached.
